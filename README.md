# java-baseball-precourse
## 기능 정리 
- 게임을 종료한 후 게임을 다시 시작하거나 완전히 종료 가능
- 상대방의 역할을 컴퓨터가 진행. 컴퓨터는 서로 다른 임의의 수 3개 생성
- 입력 및 출력
- 컴퓨터의 수 맞추기 검증
  - 위 과정을 반복해 컴퓨터가 선택한 3개의 숫자를 모두 맞히면 게임 종료
- 힌트
  - 같은 수가 같은 자리에 있으면 스트라이크, 다른 자리에 있으면 볼, 같은 수가 전혀 없으면 포볼 또는 낫싱이란 힌트
- 에러처리
  - 사용자가 잘못된 값을 입력할 경우 [ERROR]로 시작하는 에러 메시지 출력하고 게임 계속 가능
